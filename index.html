HEAL Calculators

Embeddable calculators hosted on GitHub Pages. Two ways to include them on your site. In both cases the domain of the including page must be on the allowlist (see below).

All calculators share one style definition (shared/heal.css) and the brand watermark (shared/logo.svg), so they look consistent on every site.

Option 1 - iframe (recommended)

Simplest option. Fully isolated from your page's CSS and scripts.

<iframe
  src="https://<user>.github.io/<repo>/bmi/"
  width="380"
  height="420"
  style="border:0"
  title="BMI Calculator"
  loading="lazy">
</iframe>

Option 2 - script tag

The calculator renders directly inside your page (in a shadow root, so styles stay isolated).

<div data-heal-calculator="bmi"></div>
<script src="https://<user>.github.io/<repo>/bmi/embed.js"></script>

Place the <div> where the calculator should appear. The script can go anywhere in the page; it waits for the DOM to be ready.

Controlling which sites may embed

All calculators share one allowlist: allowed-domains.js at the root of this repository. Edit it once and it applies to every calculator and both embed methods.

window.HEAL_ALLOWED_DOMAINS = [
  "example.com",       // exact domain
  "*.example.org",     // example.org + all subdomains
];
  • Not on the list → the calculator shows "not available on this site" instead.
  • Opening the calculator URL directly (not embedded) always works.
  • localhost is on the list by default for local testing.

Limitation: GitHub Pages is static hosting, so this check runs in the visitor's browser. It reliably blocks unwanted embedding of the hosted files, but it cannot stop someone from copying the files and re-hosting them without the check.

Usage statistics

Each calculator anonymously counts how often it is loaded and on which domain, using GoatCounter (EU-hosted, open source, no cookies, no personal data). Blocked embed attempts are counted separately under /blocked/…. Nothing the user enters is ever sent anywhere.
